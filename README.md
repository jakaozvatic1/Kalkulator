# Preprost kalkulator

Majhna spletna aplikacija za preizkušanje osnov Gita in GitHuba.

## Funkcionalnosti

- seštevanje;
- odštevanje;
- množenje;
- deljenje;
- preverjanje praznih vnosov;
- preprečevanje deljenja z nič.

## Zagon

Odpri datoteko `index.html` v spletnem brskalniku. Dodatna namestitev ni potrebna.

## Datoteke

- `index.html` – struktura strani;
- `style.css` – oblikovanje;
- `script.js` – računska logika;
- `.gitignore` – datoteke, ki jih Git ignorira.
Test spremembe za ukaz git diff.
Spremembe sem preizkusil v razvojni veji.
